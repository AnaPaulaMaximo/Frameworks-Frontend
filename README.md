## ⚙️ Como executar os projetos localmente

Para rodar a maioria dos projetos (baseados em Node.js/React/Next) na sua máquina, siga o padrão abaixo. Pelo terminal:

1. Clone o repositório ou navegue até a pasta do projeto específico:
```bash
# Exemplo acessando o projeto da Aula 03
cd "Aula 03/meu-projeto-next"
```

2. Instale as dependências listadas no `package.json` (e `package-lock.json`):
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
# ou
npm start
```
*O projeto estará disponível no seu navegador, geralmente em `http://localhost:3000` ou `http://localhost:5173`.*
