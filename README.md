# 📚 Frameworks Frontend - Repositório de Aulas

Este repositório foi criado para organizar todos os materiais, anotações, relatórios e projetos práticos desenvolvidos durante as aulas da disciplina de **Frameworks Frontend**.

## 📂 Estrutura do Repositório

O repositório está organizado por aulas (`Aula 01`, `Aula 02`, etc.). Cada pasta de aula contém:
- **Material Teórico:** Slides e PDFs com a contextualização da matéria ciplina e Contextualização.
- **Projetos/Atividades:** O código-fonte das aplicações desenvolvidas na respectiva aula.
